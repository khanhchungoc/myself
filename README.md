# Ngoc Khanh Chu — Online CV

**Live site:** https://khanhchungoc.github.io/myself/

A single-sheet, print-safe CV built with React and Vite. A downloadable A4 PDF is available from the live site.

## Development

```bash
npm install
npm run dev     # local dev server
npm run build   # production build
npm run pdf     # build and regenerate cv.pdf
```

See [docs/](./docs) for the content, spec, and design system.
